# QA checklist for v0.1.0

Owner's play-test before (or right after) the first public release. Test the
**released zip**, not a dev build: download it from the GitHub release, unzip
it into a fresh folder and run it with a fresh data folder if possible.

Mark each line `[x]` when it works, or write a note under it when it does
not. Anything broken becomes an issue in `docs/issues/`.

## 0. Release

- [ ] The draft release "kan! v0.1.0" has 4 zips (win-x64, osx-arm64, osx-x64, linux-x64) and the notes from `docs/releases/v0.1.0.md`.
- [ ] Published as a normal release (not pre-release).
- [ ] The website's download button points at this release and picks the right zip for your system.
- [ ] Linux zip: unzips, runs, the window title and icon say kan!.

## 1. Website (kan.kairophos.link)

- [ ] Loads on desktop and on a phone; the menu works; no horizontal scroll on the phone.
- [ ] Screenshots load; dividers stay inside the content column.
- [ ] Download section: the "Your system" card is right; the other systems are reachable.
- [ ] Sign-up form: a new account is created (success message).
- [ ] Sign-up form rejects: a short or weak password, a taken username, a taken email.
- [ ] `#password` section explains what to do after a forgotten password.
- [ ] Opening https://kan-api.kairophos.link in a browser goes to the website.
- [ ] Search result preview (share the link in a chat app): title, description and image look right.

## 2. First launch

- [ ] Intro plays silent, no osu! audio or art.
- [ ] Main menu: no osu!-only entries (osu!stable import, osu! links, osu!supporter).
- [ ] Settings: the kan! section exists (instrument, range, note size, adaptive scale, tuning).
- [ ] The microphone is picked up (input level moves when you play).
- [ ] No error notifications after a minute idle on the menu (realtime services are quiet).
- [ ] Starter pack (0.1.2 on): with a fresh data folder, the five levels are in song select, with no "Imported" notifications; the zip's `levels/` folder still holds its five .osz afterwards; closing and reopening does not import them again.
- [ ] Each starter level opens with one bar of soft pulses before the first note; Amazing Grace starts with its tune, not with a verse of organ.

## 3. Account in the game

- [ ] Sign in with the account made on the website.
- [ ] The login panel shows your profile (no endless waiting).
- [ ] Sign out, sign in again; restart the game, still signed in.
- [ ] Create a second account from the game; no osu! wording in the form.
- [ ] Wrong password shows a clear message.
- [ ] "Forgot password" opens the website at `#password`.
- [ ] Playing and kan!forge work signed out too.

## 4. Settings (kan! section)

- [ ] Instrument: choose ocarina; also "As the level".
- [ ] Range: a level outside the range moves by octaves into it.
- [ ] "Only levels that fit": song select hides levels that do not fit; `fits=no` search shows them.
- [ ] Note size changes the staff.
- [ ] Adaptive scale on/off changes how fast passages are spaced.
- [ ] Learn tuning on: a slightly sharp/flat instrument still judges right. Off: the manual cents value applies.

## 5. Playing a level

- [ ] Song select lists the level; preview audio plays.
- [ ] Song select, under the title and stars: "My instrument" shows your instrument, range and how the selected level fits; it updates as you move between levels.
- [ ] Clicking it opens the choices: change instrument (range resets to its usual one), change the range (kept when you reopen), "Only levels my instrument plays" filters the list right away.
- [ ] The player loader's side panel shows only notation and microphone (no instrument or range there).
- [ ] Notes travel by pitch; note names show; the now-line is clear.
- [ ] Correct pitch on time: hit. Wrong pitch: not a hit. Silence: miss.
- [ ] Judging is forgiving by default (near notes still count).
- [ ] Companion plays under you; reference as chosen.
- [ ] Pause, resume, restart, quit.
- [ ] Results screen: score, accuracy, no osu!-only panels.
- [ ] Signed in: the score is submitted and shows on the leaderboard.
- [ ] Ambient noise (talking, a fan) does not trigger notes.

## 6. Mods

Check each one plays as its description says, and that none changes the pitch.

- [ ] Wait for me: stops at each note until you play it; live pitch higher/lower; held soft sound; cannot fail; almost no score.
- [ ] Practice: From/To section; loops the part; arrows move, W waits, S slows, L listens; loop count shows; no score.
- [ ] Half time: slower, same pitch; speed slider down to 50 %.
- [ ] Double time: faster, same pitch; up to 200 %.
- [ ] Easy: wider timing, ±75 cents.
- [ ] Hard rock: only stricter timing; health and pitch tolerance unchanged.
- [ ] Hidden: notes fade before the line.
- [ ] By heart: each note shows for "Seen for (ms)" then disappears; incompatible with Hidden.
- [ ] No fail, Sudden death, Perfect ("SS or quit").
- [ ] Muted, Autoplay, Cinema: autoplay plays the level perfectly.
- [ ] Daycore and Nightcore are gone.
- [ ] Score multipliers shown in the mod panel make sense.

## 7. kan!forge (making a level)

- [ ] New level from a song file on disk (mp3, ogg, wav; also a video file).
- [ ] Tracks screen: tracks listed with roles (companion, reference); listen buttons; mixer.
- [ ] Split the song into its parts: first run downloads the model once; progress shows; the parts appear.
- [ ] Automatic notes: the score is written from the melody.
- [ ] Compose (piano roll): add, move, delete, resize notes; undo/redo; key audition; spectrogram layer; sections panel; shortcuts panel.
- [ ] Tempo grid and timing repair: a timing edit moves companion, reference and score together.
- [ ] Range filter panel.
- [ ] Design screen: sections, metadata, credits, instrument.
- [ ] Mic calibration and the live play-through (test the level from the editor).
- [ ] Record a take from the microphone.
- [ ] Save, close, reopen: everything is kept.
- [ ] Export the level and import it into a clean game.
- [ ] Signed in, File > "Submit level...": the wizard speaks of levels; its links open the handbook and the issue tracker.
- [ ] Submit as Work in progress: the result card says "mapped by" you, WIP.
- [ ] The level shows on your profile (beatmaps section) and in the listing under "Pending & WIP", not in the default listing.
- [ ] Owner: `npm run admin -- levels`, then `set-status <id> rank`: the level moves to the default listing and gets a leaderboard.
- [ ] Update the level and submit again: it updates the same level (no duplicate).

## 8. Online, quietly

- [ ] Chat, multiplayer and spectating are absent or say "not yet", without errors.
- [ ] Beatmap listing (level downloads) opens; empty catalogue is shown calmly.
- [ ] No osu! news, osu! wiki or osu! store links anywhere.

## 9. Other systems (with testers)

- [ ] Windows 10/11: SmartScreen warning as the notes say; runs; microphone works.
- [ ] macOS Apple silicon: "cannot check the developer"; Control-click Open; microphone permission prompt; runs.
- [ ] macOS Intel: same.

## 10. Server (owner, over SSH)

- [ ] `docker compose ps`: all healthy.
- [ ] Last night's backup is on R2 (`kan-backup.service` log).
- [ ] The admin CLI lists the test accounts; delete the throwaway ones.
