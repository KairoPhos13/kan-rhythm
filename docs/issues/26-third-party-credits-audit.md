# Third-party credits and licence audit before the public release

Labels: `licensing`, `docs`
Size: S

## Context

"License compliance is ship-blocking" is a rule of the repository
([CONTRIBUTING.md §6](https://github.com/KairoPhos13/kan-rhythm/blob/main/CONTRIBUTING.md),
[game/README.md — Ground rules](https://github.com/KairoPhos13/kan-rhythm/blob/main/game/README.md)).
The client ships `THIRD_PARTY_NOTICES` (generated by
`game/tools/gen-third-party-notices.py`, embedded and shown in the about
screen — forks F-5/F-6/F-7), but the release picture has moved since it
was written: kan!'s brand assets now exist in `game/brand/`, osu!'s UI
sounds and fonts are still used (CC BY-NC 4.0 / their own licences,
non-commercial use, credited), the audio stack's status is documented in
[game/docs/bass-licensing.md](https://github.com/KairoPhos13/kan-rhythm/blob/main/game/docs/bass-licensing.md),
and new dependencies have entered `libkan`/editor tooling over time.

A fresh, complete, human-readable credits/audit pass is cheap insurance
before strangers download the game — and contributors deserve their
names on the tin.

## What to do

1. Regenerate and review `THIRD_PARTY_NOTICES` for the current build:
   run `game/tools/gen-third-party-notices.py`, check the NuGet closure
   is current, the upstream MIT text is intact, and the BASS terms
   pointer matches
   [game/docs/bass-licensing.md](https://github.com/KairoPhos13/kan-rhythm/blob/main/game/docs/bass-licensing.md).
2. Audit the **non-code** surface:
   - every file in `game/brand/` has author + licence recorded
     (provisional generator output: note the generator as source);
   - osu!'s remaining resources (UI sounds, fonts — CC BY-NC 4.0,
     used non-commercially, credited) are listed where players see
     them (about screen / notices);
   - `assets/` ground rules applied: no GPL/AGPL assets; provenance
     recorded per
     [assets/README.md](https://github.com/KairoPhos13/kan-rhythm/blob/main/assets/README.md).
3. Audit the **native/third-party** components of `libkan`/`kanfx`/
   tooling against the MIT/BSD/Apache-only policy
   ([libkan/TODO.md — Rules](https://github.com/KairoPhos13/kan-rhythm/blob/main/libkan/TODO.md),
   ADR-0003), and ensure each appears in the notices where it ships.
4. Check the compliance hygiene items from
   [CONTRIBUTING.md §6](https://github.com/KairoPhos13/kan-rhythm/blob/main/CONTRIBUTING.md):
   upstream copyright headers preserved on adapted code; the
   "substantially modified" marking policy applied (see
   [game/docs/fork-divergence.md](https://github.com/KairoPhos13/kan-rhythm/blob/main/game/docs/fork-divergence.md)).
5. Write the result as a short checklist doc (e.g. `docs/release-credits.md`)
   a maintainer can sign off before publishing: what ships, under which
   licence, credited where. Anything missing → file it as its own issue.

## Acceptance criteria

- [ ] `THIRD_PARTY_NOTICES` regenerated and reviewed against the current
      dependency set (and still embedding + visible in the about screen)
- [ ] Every `game/brand/` file has author + licence recorded
- [ ] osu!'s CC BY-NC resources (UI sounds, fonts) listed and credited
      in player-visible places
- [ ] `libkan`/`kanfx`/tooling dependencies checked against the
      MIT/BSD/Apache policy
- [ ] Copyright headers/marking policy spot-checked on adapted fork
      files
- [ ] A sign-off checklist doc exists; gaps filed as separate issues
