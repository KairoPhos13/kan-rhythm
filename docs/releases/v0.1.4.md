kan! can now find the right microphone by itself, by listening.

Website: https://kan.kairophos.link

## New

- **Check my microphones.** Some inputs clean up the sound for calls and fade a held note away while you still play it (the Steam Deck's default input does). In *Settings > Rulesets > kan!*, open the guide's microphone step and press *Check my microphones*: hold one note, every input listens at once, and kan! keeps the one that holds your note best. It goes by how each input sounds, not by its name, so it keeps working when names change.
- While you play in the microphone step, kan! tells you if a held note is fading, and suggests the check.
- If the microphone you chose is not there any more (unplugged, or renamed by an update), kan! says so and listens to the default until you choose again.

## Install

If you installed v0.1.3 with one of the self-updating packages, kan! offers this version by itself: accept, and it restarts on v0.1.4. Otherwise pick the file for your system:

| System | Updates itself | Plain zip |
|---|---|---|
| Windows 10 or 11, 64-bit | `kan-win-x64-Setup.exe` (installs kan!) or `kan-win-x64-Portable.zip` | `kan-win-x64.zip` |
| macOS 14 or newer, Apple silicon | `kan-osx-arm64-Portable.zip` | `kan-osx-arm64.zip` |
| macOS 14 or newer, Intel | `kan-osx-x64-Portable.zip` | `kan-osx-x64.zip` |
| Linux, 64-bit | `kan-linux-x64.AppImage` (make it executable, then open it) | `kan-linux-x64.zip` |

kan! is not signed yet. Windows: *More info*, then *Run anyway*. macOS: Control-click kan! and choose *Open*.
