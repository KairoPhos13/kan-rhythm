kan! now really updates itself. v0.1.2 brought the update packages, but it still took itself for a developer build and never looked for a new version.

Website: https://kan.kairophos.link

## Fixed

- **Updates from inside the game work.** Install kan! with one of the packages below and it checks for new versions by itself: when one is ready it downloads in the background and asks before restarting. It never updates during a level.
- The game no longer says "developer build" in the corner.
- Error messages no longer claim they were reported automatically: kan! sends nothing anywhere.
- After an update, the "updated" notice opens that version's release notes on GitHub.

## Install

**If you have v0.1.1 or v0.1.2, install this version by hand once.** Neither can update itself; from v0.1.3 on, kan! keeps itself up to date. Your levels, scores and settings stay where they are.

| System | Updates itself | Plain zip |
|---|---|---|
| Windows 10 or 11, 64-bit | `kan-win-x64-Setup.exe` (installs kan!) or `kan-win-x64-Portable.zip` | `kan-win-x64.zip` |
| macOS 14 or newer, Apple silicon | `kan-osx-arm64-Portable.zip` | `kan-osx-arm64.zip` |
| macOS 14 or newer, Intel | `kan-osx-x64-Portable.zip` | `kan-osx-x64.zip` |
| Linux, 64-bit | `kan-linux-x64.AppImage` (make it executable, then open it) | `kan-linux-x64.zip` |

The plain zips work as before but do not update themselves.

kan! is not signed yet. Windows: *More info*, then *Run anyway*. macOS: Control-click kan! and choose *Open*.
