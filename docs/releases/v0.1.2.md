kan! can now update itself, and a few things found in play-testing are fixed.

Website: https://kan.kairophos.link

## New

- **Updates from inside the game.** Install kan! with one of the new packages below and it checks for new versions by itself: when one is ready it downloads in the background and asks before restarting. It never updates during a level.
- **Every level in the online listing.** The level listing opens on all levels, newest first, so new and work-in-progress levels are easy to find and try. Choose *Has Leaderboard* or *Ranked* to see only ranked levels.

## Changed

- Notes are coloured by pitch from the start. You can still turn it off in *Settings > Rulesets > kan!*.

## Fixed

- No more "unhandled error" messages during play.
- osu!'s menu music no longer plays at the main menu after a while.

## Install

New this time: packages that keep kan! up to date. Pick the one for your system.

| System | Updates itself | Plain zip |
|---|---|---|
| Windows 10 or 11, 64-bit | `kan-win-x64-Setup.exe` (installs kan!) or `kan-win-x64-Portable.zip` | `kan-win-x64.zip` |
| macOS 14 or newer, Apple silicon | `kan-osx-arm64-Portable.zip` | `kan-osx-arm64.zip` |
| macOS 14 or newer, Intel | `kan-osx-x64-Portable.zip` | `kan-osx-x64.zip` |
| Linux, 64-bit | `kan-linux-x64.AppImage` (make it executable, then open it) | `kan-linux-x64.zip` |

The plain zips work as before but do not update themselves. Your levels, scores and settings stay where they are whichever you choose.

kan! is not signed yet. Windows: *More info*, then *Run anyway*. macOS: Control-click kan! and choose *Open*.
