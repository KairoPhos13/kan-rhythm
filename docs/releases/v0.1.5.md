A small fix for the microphone check.

Website: https://kan.kairophos.link

## Fixed

- After *Check my microphones*, the microphone step could say the microphone could not be opened, and stay that way. Some inputs take one program at a time (the Steam Deck's "acp5x"), and the system's own input can keep the hardware for a few seconds after the check. kan! now waits for the microphone ("Waiting for the microphone…") instead of giving up.
- The check opens the system's default input last, so it can no longer keep a raw input from hearing your note during the check.

## Install

If you have v0.1.3 or v0.1.4 from one of the self-updating packages, kan! offers this version by itself. Otherwise pick the file for your system:

| System | Updates itself | Plain zip |
|---|---|---|
| Windows 10 or 11, 64-bit | `kan-win-x64-Setup.exe` (installs kan!) or `kan-win-x64-Portable.zip` | `kan-win-x64.zip` |
| macOS 14 or newer, Apple silicon | `kan-osx-arm64-Portable.zip` | `kan-osx-arm64.zip` |
| macOS 14 or newer, Intel | `kan-osx-x64-Portable.zip` | `kan-osx-x64.zip` |
| Linux, 64-bit | `kan-linux-x64.AppImage` (make it executable, then open it) | `kan-linux-x64.zip` |

kan! is not signed yet. Windows: *More info*, then *Run anyway*. macOS: Control-click kan! and choose *Open*.
