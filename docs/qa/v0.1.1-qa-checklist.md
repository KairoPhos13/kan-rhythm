# QA checklist for v0.1.1

Owner's play-test of v0.1.1 (published 2026-11-13): the starter pack, the
first-run guide and calibration, accessibility settings, level submission,
and the fixes from the November 2026 audit. Test the **released zip**
where possible, with a fresh data folder for sections 2 to 4.

Mark each line `[x]` when it works, or write a note under it when it does
not. Anything broken becomes an issue in `docs/issues/`.

Already checked by Claude in the isolated instance before the release:
the five starter levels on autoplay (every note judged), calibration
with a synthetic tone (35 cents flat measured as 35), the deuteranopia
palette with text at 150 %, every step of the first-run guide, and the
server's search and sign-in after the deploy.

## 1. Install from the release

- [x] The zip carries `levels/` (5 levels), `licenses/` (7 files), `LICENCE` and `THIRD_PARTY_NOTICES.md`.
- [x] Linux: opens without errors.
- [ ] Windows: opens after *More info > Run anyway* and does not close at start (the portable native library).
- [ ] macOS: opens with Control-click > *Open*.

## 2. First launch (fresh data folder)

- [x] Only kan!'s guide shows, not osu!'s.
- [x] Steps: welcome, instrument, microphone, calibration, first level (suggests Xicochi).
- [x] No technical toasts and no five "Imported" toasts.
- [x] Closing the guide halfway: it never shows again by itself.
- [x] It opens again from *Settings > Rulesets > kan!*.

## 3. Calibration with a real instrument and microphone

- [x] Microphone delay: four clicks in, eight notes; a result in milliseconds.
      Note: recognition sometimes lags and an on-time attack shows late (issue 38).
- [x] Room sound: three quiet seconds; afterwards background noise does not count as a note.
- [x] Tuning: hold a note, the result in cents; *Use it* stores it and it shows in Settings.
- [x] Every step can be skipped and repeated.

## 4. Starter pack

- [x] The 5 levels appear without an account.
- [ ] They are not duplicated on a second launch.
- [ ] Each shows its real length and stars (never 00:00 or ★0).
- [ ] One bar of soft pulses before the first note.
- [ ] Amazing Grace starts almost at once, without the long organ prelude.
- [ ] Play all five on the ocarina; note any that feel unfair or too hard.
- [ ] Each level's credits show.
- [ ] Note size readable on every screen used (issue 36 for the Steam Deck).

## 5. Upgrade over an existing install (usual data folder)

- [ ] Replacing the game folder keeps levels, scores and settings.
- [ ] The 5 new levels appear.
- [ ] The first-run guide does not show again: the data folder already marks it done (Steam Deck, v0.1.2 AppImage over a v0.1.1 data folder). To see it again, open it from *Settings > Rulesets > kan!*, or start once with the data folder moved aside.
- [ ] Older levels that read 00:00 now show their length.
- [ ] No osu! intro music at the main menu after waiting (fixed after v0.1.1; check again on the next tag).

## 6. Live judging (audit fixes)

- [ ] One wrong note right before a chord counts as one miss, not one per chord note.
- [ ] In a replay, rewinding a little re-judges the notes; none stays "not heard".
- [ ] Health, failing, streaks and the difficulty mods behave as before.
- [ ] No "unhandled error" toasts during play (fixed after v0.1.1; check again on the next tag).

## 7. Accessibility

- [ ] The three colour-blind palettes, in song select and in play.
- [ ] Text at 150 %: nothing clipped or overlapping.

## 8. Editor (kan!forge)

- [ ] Open a level, edit the score, save, leave, reopen: nothing lost.
- [ ] Replace a level's audio: the new audio is saved, the old one removed only after.
- [ ] Split a song into parts: the model downloads and is checked; note how long the split takes on the CPU (slower since the portable baseline).
- [ ] Track analysis finishes without freezing the screen.

## 9. Level submission and server

- [ ] Sign in from the game; a wrong password gives the normal message.
- [ ] *File > Submit level...*: first *Work in progress*, then *Pending*.
- [ ] The level appears on kan.kairophos.link with you as its creator.
- [ ] Your website profile shows your levels and your last visit (issue 30 for the empty fields).
- [ ] Set it to ranked with the admin tools; play it; your score is on its leaderboard.
- [ ] Several failed sign-ins lock only that account for a while; another account still signs in.
- [ ] The game's online search lists levels (issue 37).

## 10. Public texts

- [ ] The README's quick start reads well on GitHub.
